# 猫课 CRM — 系统级用例（按角色）

本文档从**系统/业务**视角描述用例，先以**用例清单**形式列出；细化场景、前置条件与异常流可在评审后补充。

**角色**：`super_admin`（超级管理员）、`admin`（管理员）、`sales`（销售）、`consultant`（咨询师）。

**编号规则**：`UC-{角色缩写}-{序号}`。角色缩写：`SA` 超管、`AD` 管理员、`SL` 销售、`CO` 咨询师。

---

## 一、全体已认证用户共通用例

| 编号 | 用例名称 | 主要参与者 | 简述 |
|------|----------|------------|------|
| UC-COM-01 | 用户登录 | 四类角色 | 使用用户名（手机或邮箱）与密码获取访问令牌与刷新令牌。 |
| UC-COM-02 | 刷新访问令牌 | 四类角色 | 使用刷新令牌换取新的访问令牌。 |
| UC-COM-03 | 用户登出 | 四类角色 | 服务端记录登出（JWT 场景下以客户端清除令牌为主）。 |
| UC-COM-04 | 查看当前用户资料 | 四类角色 | 获取当前登录用户基本信息及角色。 |
| UC-COM-05 | 查看角色字典 | 四类角色 | 获取系统内角色列表（创建用户时选用）。 |

## 二、超级管理员（super_admin）

> 在系统中具备**不低于管理员**的全部管理类能力，并在用户生命周期上多出**删除用户**权限。

| 编号 | 用例名称 | 主要参与者 | 简述 |
|------|----------|------------|------|
| UC-SA-01 | 分页查询用户 | super_admin | 按关键词、角色、状态筛选用户列表。 |
| UC-SA-02 | 创建用户 | super_admin | 创建任意业务角色用户并设置初始密码与联系方式。 |
| UC-SA-03 | 查看用户详情 | super_admin | 按用户 ID 查看单条用户资料。 |
| UC-SA-04 | 更新用户 | super_admin | 修改用户姓名、联系方式、状态、角色等。 |
| UC-SA-05 | 删除用户 | super_admin | 删除指定用户（系统约束：不可删除自身账号）。 |
| UC-SA-06 | 管理系统配置入口 | super_admin | 通过前端「设置」等管理入口访问仅管理员可见功能（与 admin 共用界面权限）。 |
| UC-SA-07 | 查询审计日志 | super_admin | 分页、多条件查询操作审计记录。 |
| UC-SA-08 | 查看审计统计 | super_admin | 查看审计日志聚合统计（按动作、资源类型等）。 |
| UC-SA-09 | 查看审计元数据 | super_admin | 获取审计动作类型、资源类型等下拉/字典数据。 |
| UC-SA-10 | 执行数据导入 | super_admin | 上传文件导入课程购买或上课记录，并查看批次与失败明细。 |
| UC-SA-11 | 全量客户管理 | super_admin | 创建客户时可指定负责人；按负责人筛选列表；软删除客户；更新客户状态与档案。 |
| UC-SA-12 | 全量标签管理 | super_admin | 含创建、更新、**删除**标签。 |
| UC-SA-13 | 全量跟进与机会管理 | super_admin | 查看全部跟进/机会看板；代任意客户维护机会阶段与记录。 |
| UC-SA-14 | 全量提醒管理 | super_admin | 查看提醒；为团队创建提醒；代执行人完成或删除提醒。 |
| UC-SA-15 | 创建服务记录 | super_admin | 为客户登记咨询服务记录。 |
| UC-SA-16 | 查看任意客户时间线 | super_admin | 聚合查看指定客户全生命周期事件。 |
| UC-SA-17 | 使用工作台与业务导航 | super_admin | 访问仪表盘及全部已开放业务菜单。 |

## 三、管理员（admin）

> 与超管相比，**不能删除用户**；其余管理类能力（用户维护、审计、导入、客户删除、标签删除等）与超管对齐（以当前代码为准）。

| 编号 | 用例名称 | 主要参与者 | 简述 |
|------|----------|------------|------|
| UC-AD-01 | 分页查询用户 | admin | 同 UC-SA-01。 |
| UC-AD-02 | 创建用户 | admin | 同 UC-SA-02（通常为销售、咨询师等）。 |
| UC-AD-03 | 查看用户详情 | admin | 同 UC-SA-03。 |
| UC-AD-04 | 更新用户 | admin | 同 UC-SA-04。 |
| UC-AD-05 | 查询审计日志 | admin | 同 UC-SA-07。 |
| UC-AD-06 | 查看审计统计 | admin | 同 UC-SA-08。 |
| UC-AD-07 | 查看审计元数据 | admin | 同 UC-SA-09。 |
| UC-AD-08 | 执行数据导入 | admin | 同 UC-SA-10。 |
| UC-AD-09 | 全量客户管理 | admin | 含指定负责人、筛选、软删除、状态与档案维护；同 UC-SA-11。 |
| UC-AD-10 | 全量标签管理 | admin | 含删除标签；同 UC-SA-12。 |
| UC-AD-11 | 全量跟进与机会管理 | admin | 同 UC-SA-13。 |
| UC-AD-12 | 全量提醒管理 | admin | 同 UC-SA-14。 |
| UC-AD-13 | 创建服务记录 | admin | 同 UC-SA-15。 |
| UC-AD-14 | 查看任意客户时间线 | admin | 同 UC-SA-16。 |
| UC-AD-15 | 使用工作台与业务导航 | admin | 同 UC-SA-17（含导入/用户/审计/设置等管理菜单）。 |

**说明**：管理员**不包含**「删除用户」用例（对应 UC-SA-05）。

## 四、销售（sales）

> 聚焦**本人客户**上的销售行为；**无**用户管理、审计、批量导入及前端管理菜单（以当前前后端实现为准）。

| 编号 | 用例名称 | 主要参与者 | 简述 |
|------|----------|------------|------|
| UC-SL-01 | 使用工作台与客户菜单 | sales | 访问仪表盘、客户、跟进、机会、服务记录、提醒等业务页。 |
| UC-SL-02 | 创建客户（本人负责） | sales | 新建客户档案；负责人默认为当前销售，不可指定为他人。 |
| UC-SL-03 | 维护客户档案 | sales | 在权限允许范围内更新客户信息与标签（实现上与 PRD「仅负责客户」可能存在差异，以代码为准）。 |
| UC-SL-04 | 查看客户时间线（权限范围内） | sales | 查看客户聚合时间线；**非管理员**时通常仅限**本人负责**的客户。 |
| UC-SL-05 | 维护本人跟进记录 | sales | 列表仅看本人跟进；对**本人负责客户**新增跟进；删除本人创建的跟进。 |
| UC-SL-06 | 维护本人销售机会 | sales | 查看机会列表与看板；对 **`owner_user_id` 为自己** 的机会进行创建、更新、改阶段、删除。 |
| UC-SL-07 | 使用服务记录列表 | sales | 查看服务记录列表（是否可写服务记录由接口角色约束：销售默认仅列表只读场景，以产品定义为准）。 |
| UC-SL-08 | 管理提醒（执行人或管理员） | sales | 创建提醒；将**指派给自己**的提醒标为完成或删除（管理员可覆盖更多场景）。 |
| UC-SL-09 | 使用标签（非删除） | sales | 查看标签；创建、更新标签；**不可**删除标签。 |
| UC-SL-10 | 查看角色字典 | sales | 为理解系统角色使用（无用户管理入口）。 |

**说明**：销售**不包含**：删除客户、删除用户、审计查询、导入批次、删除标签、前端「用户/导入/审计/设置」菜单（若仅依赖路由控制）。

## 五、咨询师（consultant）

> 侧重**服务侧**记录与协同；销售类「负责人」约束与提醒、时间线等规则与 sales 类似，并明确具备**服务记录录入**能力。

| 编号 | 用例名称 | 主要参与者 | 简述 |
|------|----------|------------|------|
| UC-CO-01 | 使用工作台与客户菜单 | consultant | 访问仪表盘、客户、跟进、机会、服务记录、提醒等（无管理类菜单）。 |
| UC-CO-02 | 查看与协作客户资料 | consultant | 在权限范围内查看/更新客户（PRD 期望脱敏展示；当前实现可能未掩码，以代码为准）。 |
| UC-CO-03 | 查看客户时间线（权限范围内） | consultant | 同 UC-SL-04：非管理员通常仅**本人负责客户**的时间线。 |
| UC-CO-04 | 创建服务记录 | consultant | 为客户登记咨询/服务过程与满意度等。 |
| UC-CO-05 | 查看服务记录列表 | consultant | 按列表筛选查看历史服务记录。 |
| UC-CO-06 | 维护跟进（在客户负责人规则下） | consultant | 对**负责人为自己**的客户添加跟进；列表仅看本人跟进；删除本人跟进。 |
| UC-CO-07 | 维护机会（在机会负责人规则下） | consultant | 对 **`owner_user_id` 为自己** 的机会进行维护（与 sales 规则一致）。 |
| UC-CO-08 | 管理提醒（执行人或管理员） | consultant | 同 UC-SL-08。 |
| UC-CO-09 | 使用标签（非删除） | consultant | 同 UC-SL-09。 |
| UC-CO-10 | 查看角色字典 | consultant | 同 UC-SL-10。 |

**说明**：咨询师**不包含**：删除客户、用户管理、审计、导入、删除标签、管理菜单；若机构将咨询师设为部分客户的负责人，则 UC-CO-03 / UC-CO-06 / UC-CO-07 在「本人负责」范围内生效。

## 六、用例与角色覆盖矩阵（摘要）

| 能力域 | super_admin | admin | sales | consultant |
|--------|-------------|-------|-------|------------|
| 登录 / 令牌 / 个人资料 | ✓ | ✓ | ✓ | ✓ |
| 用户删除 | ✓ | — | — | — |
| 用户增改查（除删除） | ✓ | ✓ | — | — |
| 审计 / 导入 / 设置类菜单 | ✓ | ✓ | — | — |
| 客户删除 / 指定负责人 | ✓ | ✓ | — | — |
| 标签删除 | ✓ | ✓ | — | — |
| 创建客户（默认本人负责） | ✓ | ✓ | ✓ | ✓* |
| 服务记录创建 | ✓ | ✓ | —** | ✓ |
| 时间线（全量） | ✓ | ✓ | — | — |
| 时间线（本人客户） | — | — | ✓ | ✓ |

\* 咨询师创建客户行为以产品是否开放为准；代码上若开放则负责人逻辑同销售。  
\*\* 当前后端对 `POST /services/records` 限制为 consultant / admin / super_admin；销售默认不包含「创建服务记录」用例。
